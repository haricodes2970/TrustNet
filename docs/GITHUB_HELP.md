# GitHub Help

## Branching

- `main` - stable code.
- `develop` - integration branch.
- `feature/<short-name>` - new feature.
- `fix/<short-name>` - bug fix.
- `docs/<short-name>` - documentation.

## Commits

Use:

```text
type(scope): short message
```

Examples:

- `feat(auth): add refresh token rotation`
- `fix(api): validate community slug route`
- `docs(team): add role checklist`

## Pull Requests

Every PR should include summary, test proof, screenshots for frontend changes, and linked issue.
